# 📄 Analisador de Texto

**Analisador de Texto** é uma aplicação simples escrita em Python, projetada para contar o número de linhas, palavras e caracteres de um texto fornecido pelo usuário.

## ✨ Funcionalidades

- 📄 Contagem de **linhas**.
- 📝 Contagem de **palavras**.
- 🔢 Contagem de **caracteres** (incluindo espaços e quebras de linha).

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/analisador-de-texto.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd analisador-de-texto
   ```
3. Execute o script:
   ```bash
   python Analisador_de_Texto.py
   ```

## 📋 Instruções de Uso

- Digite ou cole o texto no terminal.
- Para finalizar a entrada, pressione **Enter duas vezes**.
- O programa irá exibir o resumo da análise no terminal.

### Exemplo de Uso

```bash
Bem vindo ao analisador de texto
Digite seu texto abaixo, e para finalizar pressione enter duas vezes

Olá, mundo!
Este é um exemplo de entrada.

Resultado da análise:
número de linhas: 2
número de palavras: 8
número de caracteres: 45
```
